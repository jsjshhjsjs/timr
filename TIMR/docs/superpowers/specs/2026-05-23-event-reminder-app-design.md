# TIMR — 事件提醒应用设计文档

## 概述

一个纯原生 HTML/CSS/JS 的单文件 Web 应用，用于手动记录事件并在事件将要发生时通过浏览器通知提醒用户。界面简洁美观，中文优先。

## 技术方案

| 项目 | 选择 |
|------|------|
| 技术栈 | 纯原生 HTML + CSS + JS，零依赖 |
| 文件结构 | 单个 `index.html`，内嵌所有 CSS 和 JS |
| 数据存储 | `localStorage` |
| 提醒机制 | `setInterval` 每分钟轮询 + `Notification API` |
| 运行方式 | 浏览器直接打开 HTML 文件 |

## 功能需求

### 事件管理
- **新建事件**：标题、日期时间、重复模式（一次性/每天/每周/每月）、提前提醒时间
- **编辑事件**：点击菜单按钮修改已有事件
- **删除事件**：点击菜单按钮删除，需确认

### 事件列表
- 按时间升序展示所有未过期事件
- 卡片式布局：左侧日期色块 + 标题 + 时间 + 重复标签
- 24 小时内的事件显示橙色"即将"标记
- 过期事件自动隐藏（不再显示）

### 提醒通知
- 页面加载时启动 1 分钟间隔的定时检查
- 当前时间 ≥ 事件时间 - 提前提醒时间 → 触发 Notification
- 一次提醒后标记已提醒，避免重复弹出
- 重复事件：提醒后自动推进到下一个周期

### 主题切换
- 标题栏右侧色块按钮，点击即切换
- 7 套预设: 靛蓝#4a6cf7 翠绿#10b981 暖橙#f59e0b 紫罗兰#8b5cf6 玫红#ef4444 浅粉#f472b6 青碧#48ecdf
- 通过 CSS 变量实现：`--primary` `--primary-light` `--primary-dark`
- 用户选择存入 localStorage

## 数据模型

```
Event {
  id: string,           // 唯一标识，时间戳+随机
  title: string,        // 事件标题
  datetime: string,     // ISO 日期时间 "2026-05-24T14:00"
  repeat: string,       // "none" | "daily" | "weekly" | "monthly"
  remindBefore: number, // 提前提醒分钟数，默认 15
  reminded: boolean,    // 本次是否已提醒（用于一次性事件）
  remindedDate: string, // 上次提醒日期 "2026-05-24"（用于重复事件每日重置）
  createdAt: string     // ISO 创建时间
}
```

## UI 结构

```
┌──────────────────────┐
│ 标题栏  TIMR·事件提醒  │  ← 标题 + 待处理计数 + 主题色块选择器
├──────────────────────┤
│                      │
│  ┌────────────────┐  │
│  │ [5/24] 项目周会 │  │  ← 事件卡片列表
│  │ 明天14:00 每周  │  │     左：日期色块
│  │            [即将]│  │     中：标题+时间+标签
│  └────────────────┘  │     右：⋯ 菜单
│  ┌────────────────┐  │
│  │ [5/30] 季度报告 │  │
│  │ 5/30 17:00 一次 │  │
│  └────────────────┘  │
│                      │
├──────────────────────┤
│    [+ 新建事件]       │  ← 全宽主色按钮
└──────────────────────┘
```

### 表单弹窗
- 模态弹窗覆盖主界面
- 字段：标题（文本输入）、日期时间（datetime-local）、重复模式（下拉选择）、提前提醒（下拉选择 5/10/15/30/60 分钟）
- 保存 / 取消按钮

## 非功能需求

- 适应用户系统颜色方案（跟随 light/dark 基础背景）
- 响应式布局，手机和桌面均可使用
- 首次使用显示空状态引导
- 删除操作有确认提示
